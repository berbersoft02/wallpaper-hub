# Wallpaper Hub

Responsive web application for browsing, categorizing, and previewing curated wallpapers.

## Features

- Categorized wallpaper collections with responsive grid layouts.
- Lightbox preview with touch navigation support.
- Optimized image delivery and dark/light mode compatibility.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

```bash
npm run build
```
